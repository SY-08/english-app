# English Time（英語学習アプリ）

大人用と子供用を切り替えて使う英語学習アプリです。いまは **子供用** を作っています（大人用は準備中）。

## 子供用（Unit: I Want）

| フェーズ | 内容 |
|---|---|
| ① おはなしを きこう | 絵本「I Want」を1ページずつ。日本語 → 英語の順で読み上げ。▶ぜんぶ で自動再生 |
| ② タップして きこう | Story Phrases / Shapes / Opposites / Time / Family and Friends / Commands。カードをタップすると読み上げ。すごろくも |
| ③ ゲームで あそぼう | もじさがし・てんつなぎ・おおもじこもじ・きいてえらぼう・どっちかな・かげあて |

- 読み上げはブラウザの音声合成（Web Speech API）を使います。⚙ せってい で「えいごだけ」や速さを変えられます
- 応援キャラクターは `media/` の動画を使います
  - `cheer-idle.mp4`（動画①）… ふだんはこれをループ
  - `cheer-tap.mp4`（動画②の一部）… タップしたとき・正解したとき
  - `cheer-clear.mp4`（動画③の一部）… ページやゲームをクリアしたとき
- イラストはすべて `js/art.js` で描いたオリジナルです

## 学習記録（スプレッドシート）

記録はスプレッドシートの「学習記録」シートに1行ずつたまります（日時・学習者・フェーズ・内容・結果・正解数・時間など）。

1. スプレッドシートで「拡張機能 → Apps Script」を開き、`gas/Code.gs` を貼り付けて保存
2. `setup` を一度実行
3. 「デプロイ → 新しいデプロイ → ウェブアプリ」（実行：自分／アクセス：全員）
4. 出てきた URL を `js/config.js` の `gasUrl` に入れる

URL が未設定のあいだは端末に記録をためておき、設定後にまとめて送ります。

## ファイル構成

```
index.html        画面のわく
css/style.css     見た目
js/config.js      設定（記録の送り先URL）
js/data.js        教材データ（英文・日本語・カード）
js/art.js         イラスト（SVG）
js/core.js        読み上げ・応援キャラ・学習記録
js/app.js         各画面
media/            応援キャラクターの動画
gas/Code.gs       スプレッドシート側の受け口
```

## 手元で動かす

ファイルを置いたフォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開きます。
